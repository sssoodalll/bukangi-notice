# 부캉이 안전 기사 수집기

부산 북항 친수공원 수로에 머무는 상어 **'부캉이'** 관련 **안전 기사**를 자동으로 모으고, 거르고, 검수해서
상황판 [부캉이 지금 있나](https://bukangi.com/)의 "안전 · 공지" 칸으로 넘겨 주는 모듈입니다.

- 상황판 코드: [pizzalist/where-is-bukangi](https://github.com/pizzalist/where-is-bukangi)
- 이 저장소의 범위는 **수집 → 거르기 → 검수 → 전달 API**까지입니다. 화면에 붙이는 일은 상황판 쪽에서 합니다.
- [Claude Code](https://claude.com/claude-code)와 함께 개발했습니다. 결정 과정은 [CLAUDE.md](CLAUDE.md)에 날짜별로 남겼습니다.

## 어떻게 동작하나

```
 ┌──────────────┐   1시간마다    ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
 │ Bing 뉴스 RSS │ ───────────▶ │ 단어 규칙     │──▶│ SQLite 장부   │──▶│ 판정기        │
 │ (검색어 10개) │   수집·중복 제거 │ 꼬리표·우선순위 │   │ data/        │   │ 승인 확률 0~1  │
 └──────────────┘              └──────────────┘   └──────────────┘   └──────┬───────┘
                                                                            │
          ┌───────────────────────────────┬─────────────────────────────────┘
          ▼                               ▼
 ┌──────────────────┐           ┌──────────────────┐            ┌──────────────────┐
 │ 0.8 이상: 자동 승인 │           │ 나머지: 사람 검수  │ ─ 승인 ─▶ │ GET /api/approved │ ──▶ 상황판
 │ (AI 결정 표시)      │           │ 검수 화면 /        │            │ (JSON)            │
 └──────────────────┘           └──────────────────┘            └──────────────────┘
                                         │ 사람의 승인·반려 = 판정기의 정답지 (수집 때마다 다시 학습)
```

| 단계 | 하는 일 | 파일 |
|---|---|---|
| 수집 | Bing 뉴스 RSS에서 검색어 10개 × 2쪽. 요청 사이 1초 쉼 | `collector/sources/bing_news.py` |
| 거르기 | 단어 규칙으로 꼬리표(안전/기타/인기)와 우선순위를 붙이고, 관계없는 기사는 버림 | `collector/classify.py` |
| 저장 | 같은 주소·같은 제목은 다시 넣지 않음. 검수 상태(검수 전/승인/반려)를 기록 | `collector/store.py` |
| 판정 | 사람 검수 기록으로 학습한 분류기가 승인 확률을 매김 | `collector/judge.py` |
| 검수 | 웹 화면에서 승인·반려·되돌리기 | `server/app.py` |
| 전달 | 승인된 기사만 JSON으로 제공 | `server/app.py` |
| 자동 실행 | 서버가 켜져 있는 동안 간격마다 수집 → 학습 → 판정 | `server/scheduler.py` |

## 안전 기사 기준

| 우선순위 | 종류 | 예 |
|---|---|---|
| **1순위** | **사람의 안전** | 관람객이 물에 손을 넣어 휴대폰을 건짐, 출입 통제, 단속, 사고 |
| **2순위** | **상어의 안전** | 상처·건강 상태, 불빛 비추기·먹이 투척 같은 해치는 행동, 멸종위기종이라는 정보 |
| 제외 | 구조·이동 작전, 인기·방문객 기사 | "3차 구조 추진", "방문객 150만 돌파" |

## 판정기 성능

사람이 직접 검수한 **143건**(승인 85 / 반려 58)으로, 배운 적 없는 기사를 맞히는지 5겹 교차 검증했습니다.

| 방법 | 정확도 |
|---|---|
| 단어 규칙만 | 85% |
| **판정기** (글자 2~4개 묶음 TF-IDF + 로지스틱 회귀) | **90%** |

| 자동 처리 기준 | 사람 없이 처리 | 그중 정답 |
|---|---|---|
| 승인 ≥ 0.8 / 반려 ≤ 0.2 | 3% | 4/4 |
| 승인 ≥ 0.7 / 반려 ≤ 0.3 | 38% | 54/54 |

- 현재 설정은 **자동 승인(0.8 이상)만** 켜져 있습니다. 안전 기사를 놓치는 실수(자동 반려)가 잘못 내보내는 실수보다 위험하기 때문입니다.
- 같은 사람이 같은 시기에 검수한 데이터라서, 실제 운영 성능은 이보다 낮을 수 있습니다. 검수가 쌓이면 `python run_judge.py`로 다시 잽니다.
- AI가 결정한 기사는 정답지에 넣지 않습니다. 사람이 AI 결정을 고치면 그때 정답지가 됩니다.

## 출처 정책

- robots.txt와 이용약관에서 **허용된 공개 경로만** 씁니다.
- 구글 뉴스 RSS는 robots.txt가 `/rss/` 경로를 허용하지 않아 쓰지 않습니다. 네이버·다음 검색 화면도 로봇 접근을 금지해서 쓰지 않습니다.
- 출처를 추가할 때는 `collector/sources/`에 `fetch(query) -> list[Article]` 함수를 가진 파일을 하나 더 만들고 `collector/sources/__init__.py`에 등록합니다.

## 설치

Python 3.10 이상이 필요합니다 (개발은 3.12).

```bash
git clone https://github.com/sssoodalll/bukangi-notice.git
cd bukangi-notice
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 실행

```bash
python run_server.py             # 서버 켜기 → http://localhost:8000
```

| 주소 | 내용 |
|---|---|
| `/` | 검수 화면 |
| `/api/approved` | 승인된 기사 (JSON) |
| `/docs` | 자동 생성 API 설명서 |

그 밖의 실행 파일:

```bash
python run_collect.py            # 한 번만 수집해서 장부에 넣기
python run_judge.py              # 판정기 시험(교차 검증) + 학습 + 검수 전 기사 점수
```

## 설정 (환경 변수)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `HOST` / `PORT` | `127.0.0.1` / `8000` | 서버 주소 |
| `COLLECT_INTERVAL_MIN` | `60` | 수집 간격(분). `0`이면 자동 수집 끔 |
| `AUTO_DECIDE` | `approve` | `off` 점수만 / `approve` 자동 승인만 / `both` 자동 승인 + 자동 반려 |
| `AUTO_HIGH` / `AUTO_LOW` | `0.8` / `0.3` | 자동 승인 / 자동 반려 기준 |
| `EXCLUDE_WORDS_FILE` | `exclude_words.txt` | 제외 단어 목록 파일 (선택, 없으면 제외 안 함) |

**제외 단어 목록**: 한 줄에 단어 하나씩 적고, 기사 제목에 그 단어가 있으면 수집하지 않습니다. `#`으로 시작하는 줄은 설명입니다. 운영자가 정하는 목록이라 저장소에는 넣지 않습니다.

## 전달 API

```
GET /api/approved?since=2026-10-19T00:00:00+00:00&limit=50
```

```json
{
  "count": 1,
  "articles": [{
    "id": 5,
    "title": "...",
    "url": "https://...",
    "press": "연합뉴스",
    "published_at": "2026-10-19T02:14:03+00:00",
    "category": "safety",
    "priority": 2,
    "tags": ["상어 안전:상처"],
    "reviewed_at": "2026-10-19T05:03:23+00:00",
    "decided_by": "human",
    "score": 0.74
  }]
}
```

- 최근 승인 순입니다. `since`를 주면 그 시각 이후에 승인된 기사만 줍니다. 시각은 모두 UTC입니다.
- 마지막으로 받은 기사의 `reviewed_at`을 다음 요청의 `since`로 넣으면 새 승인분만 받을 수 있습니다.
- `priority`: 1 = 사람의 안전, 2 = 상어의 안전. `decided_by`: `human` 사람 / `auto` 판정기.

## 알려진 한계

- **검수 화면에는 로그인이 없습니다.** 기본값은 이 컴퓨터에서만 접속되는 `127.0.0.1`입니다. 외부에 열 때는 인증을 붙여야 합니다.
- 판정기는 제목·요약의 글자만 봅니다. 문장의 뜻이 중요한 기사는 틀릴 수 있어서, 판정 엔진(`judge.py`)을 로컬 AI나 Claude API로 바꿔 끼울 수 있게 만들었습니다.
- 출처가 Bing 뉴스 하나입니다. 기관 공지(해경, 부산시설공단 등)는 아직 붙이지 않았습니다.
- 2026-10-19 이전에 모은 일부 기사는 주소가 news.google.com을 거칩니다 (`source=google_news`).
